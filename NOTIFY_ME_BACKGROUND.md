# V0.3.4 background preview
Deploy tools/notify-me-ai/worker.mjs (adds authenticated POST /v1/check; no D1 migration). Existing root protocol version remains 0.3.3-unified-auth. Set ENABLE_NOTIFY_CRON (Text) to true and add Cron Trigger */5 * * * * in Cloudflare. Existing tick processes one due watch per invocation; per-watch due time remains 75 minutes and backoff applies. Android WorkManager runs approximately hourly with network constraint, calls server to check one due watch for current account, then polls events and posts ordinary notifications. This is server-assisted polling, not local HTML extraction or push. Notification permission is required; events are not acknowledged when permission is absent. Stable notification tags reduce duplicates on retries; delivery is not exactly once and acknowledgement is account-wide. No notification deep link, Live Update or Instant Open in this patch. Existing settings are preview only. Sign-out cancels periodic work and clears release notifications. WorkManager handles reboot scheduling; force-stop and OS restrictions may delay work. Build and real device verification required. Existing auth/session schema unchanged.
